Seed Clustering

The goal is to group seed measurements without showing the algorithms the known `Class` labels.

## 2. K-Means function

```python
def kmeans(X, k, seed=0, starts=10, max_iter=100):
```

This function implements K-Means. Its inputs are the standardized data, the requested number of clusters `k`, a random seed, how many random initializations to try, and a limit on the number of update steps.

### Initialize the centers

```python
rng, best = np.random.default_rng(seed), None
for _ in range(starts):
    centers = [X[rng.integers(len(X))]]
```

I make a random number generator so the result can be reproduced with the same seed. For each restart, I select the first center from a random observation.

```python
for _ in range(1, k):
    d2 = ((X[:, None] - centers) ** 2).sum(axis=2).min(axis=1)
    centers.append(X[rng.choice(len(X), p=d2 / d2.sum())])
```

The next centers use **K-Means++ initialization**. For each observation, I calculate its squared distance to the nearest center already chosen. Points farther away get a higher chance of becoming the next center. This spreads out the starting centers and usually gives a better start than picking every center uniformly at random.

### Assign points and update centers

```python
for _ in range(max_iter):
    labels = ((X[:, None] - centers) ** 2).sum(axis=2).argmin(axis=1)
```

For every observation, I calculate its squared distance to each center and assign it to the nearest one. `labels` stores the cluster ID for each row.

```python
updated = np.array([
    X[labels == j].mean(axis=0) if np.any(labels == j)
    else X[rng.integers(len(X))]
    for j in range(k)
])
```

I move each center to the mean of the observations assigned to it. If a cluster becomes empty, I reset its center to a random observation so that the function can continue.

```python
if np.allclose(centers, updated, atol=1e-4): break
centers = updated
```

I stop when the centers barely move. `max_iter` is a safety limit in case they do not settle sooner.

### Keep the best restart

```python
inertia = ((X - centers[labels]) ** 2).sum()
if best is None or inertia < best[0]: best = inertia, centers, labels
return best
```

Inertia is the total squared distance from each observation to its assigned center. I save the run with the lowest inertia because that is the tightest grouping found across the random starts. The function returns the inertia, centers, and assignments.

## 3. Choose K and fit the final K-Means model

```python
scores = []
for k_try in range(2, 11):
    inertia, centers, labels = kmeans(X, k_try)
    scores.append((k_try, inertia, silhouette_score(X, labels)))
```

I try values from 2 to 10 and record two diagnostics:

- **Inertia** measures how close points are to their centers. It always decreases as K increases, so the useful signal is where the decrease starts to level off.
- **Silhouette score** measures how well separated and compact the clusters are. Higher is generally better, though it may prefer a different K from the elbow.

```python
scores = pd.DataFrame(scores, columns=['k', 'inertia', 'silhouette'])
display(scores.round(3))
scores.set_index('k')[['inertia', 'silhouette']].plot(...)
```

I put the results in a table and plot both measures so I can inspect the elbow and compare it with silhouette.

```python
k = 3
inertia, km_centers, km_labels = kmeans(X, k, seed=42, starts=30)
```

I choose K=3 based on the elbow in the inertia plot. This is a judgment from the internal clustering diagnostics, not from `Class`. I use more restarts for the final fit to reduce the chance that a poor random initialization determines the result.

## 5. DBSCAN function

```python
def dbscan(X, eps, min_samples):
    D = np.sqrt(((X[:, None] - X[None, :]) ** 2).sum(axis=2))
    neighbors = [np.flatnonzero(row <= eps).tolist() for row in D]
```

DBSCAN needs distances and neighborhoods. `D` is the pairwise Euclidean distance matrix, and `neighbors[i]` contains the rows no farther than `eps` from point `i`. Since the distance from a point to itself is zero, the point itself is included in its neighborhood; `min_samples` therefore counts it too.

```python
labels, cluster = np.full(len(X), -99), 0
```

I use `-99` internally to mean “not visited yet.” DBSCAN uses `-1` for noise, while nonnegative numbers identify clusters.

```python
for i in range(len(X)):
    if labels[i] != -99: continue
    if len(neighbors[i]) < min_samples:
        labels[i] = -1
        continue
```

I visit each point. If it does not have enough neighbors to be a core point, I mark it as noise for now. It may still be added later as a border point if it is near a core point.

```python
labels[i] = cluster
queue, seen, q = list(neighbors[i]), set(neighbors[i]), 0
while q < len(queue):
```

A point with enough neighbors starts a new cluster. The queue keeps track of points whose neighborhoods need to be explored; `seen` avoids adding the same point to the queue repeatedly.

```python
j = queue[q]; q += 1
if labels[j] == -99:
    labels[j] = cluster
    if len(neighbors[j]) >= min_samples:
        for n in neighbors[j]:
            if n not in seen: queue.append(n); seen.add(n)
elif labels[j] == -1:
    labels[j] = cluster
```

If a queued point is a core point, I add its neighbors to the queue, which lets the cluster expand through connected dense regions. If it was previously marked as noise, it is now reachable from a core point, so I reclassify it as part of this cluster. Border points can join but do not expand the cluster themselves.

```python
cluster += 1
return labels
```

Once the queue is exhausted, that density-connected cluster is complete. I move to the next unvisited core point and eventually return every assignment, including any points still marked `-1` as noise.

## 6. Select DBSCAN parameters

```python
D = np.sqrt(((X[:, None] - X[None, :]) ** 2).sum(axis=2))
choices = []
for m in (4, 5, 6, 8, 10):
    kth = np.sort(D, axis=1)[:, m - 1]
```

I calculate distances once, then try several values of `min_samples`. For each point, `kth` is the distance to its `m`-th nearest neighbor (including itself). The sorted k-distance values help set a sensible range for `eps`.

```python
for eps_try in np.quantile(kth, np.linspace(.1, .9, 25)):
```

Rather than choose one radius by eye, I test candidate `eps` values drawn from k-distance quantiles.

```python
labels = dbscan(X, eps_try, m)
keep = labels != -1
if len(np.unique(labels[keep])) > 1 and keep.sum() > len(np.unique(labels[keep])):
    score = silhouette_score(X[keep], labels[keep]) * keep.mean()
    choices.append((score, eps_try, m, labels))
```

I skip settings that produce fewer than two clusters, because silhouette needs multiple clusters. For the remaining candidates, I calculate silhouette on clustered points and multiply it by **coverage** (the fraction not labeled as noise). This discourages a parameter choice that looks well separated only because it discarded many observations. This is a heuristic, and it does not use the true labels.

```python
_, eps, min_samples, db_labels = max(choices, key=lambda r: r[0])
```

I keep the candidate with the highest selection score and print its parameters, number of clusters, and number of noise points.

## 8. Compare clusters with known classes

```python
results = pd.DataFrame({name: [
    adjusted_rand_score(y, labels),
    normalized_mutual_info_score(y, labels)
] for name, labels in [('K-Means', km_labels), ('DBSCAN', db_labels)]},
index=['ARI vs true class', 'NMI vs true class'])
```

I use two external evaluation metrics after fitting:

- **Adjusted Rand Index (ARI):** compares pairs of observations to see whether the clustering and known labels group them consistently. A score near 1 indicates strong agreement; around 0 is about what random grouping would achieve.
- **Normalized Mutual Information (NMI):** measures how much information the cluster assignments share with the known classes, scaled for easier comparison. Higher means stronger agreement.

Cluster numbers do not need to match class numbers for these metrics. I display the values rounded to three decimals.
